# Contributing

Keep changes small, focused, and documented. Before opening a pull request, build the image and verify the health check.

## Commit messages

Use the Conventional Commits format:

```
type(optional-scope): short imperative summary
```

Examples:

- `feat: add a compose example`
- `fix: wait for Tor before reporting healthy`
- `docs: clarify proxy exposure risk`

Common types are `feat`, `fix`, `docs`, `ci`, `build`, `refactor`, `test`, and `chore`.
